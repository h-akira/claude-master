# 規約
## 一般
- プロンプトの回答は日本語
- ソースコード等の新規作成の場合、indentは2スペース
- 特に指示がない限り、ソースコード中のコメントは英語で書く
- 特に指示がない限り、ドキュメントは日本語で書く
- ドキュメントではMermaidによる図の利用を推奨する
- コマンドを実行するときは必ず`cd`コマンドで絶対パスを用いて作業ディレクトリに移動してから実行する

## git関連
- `git add .`や`git add -A`は禁止で、必ず個別のファイルを指定するか`git add -u`を用いる
- 特別な指示がない限りは`git push`は禁止（ユーザーが自分で実行する）
