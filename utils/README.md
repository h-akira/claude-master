# utils

ClaudeCodeの利用状況を調べたり、日々の作業を補助したりするスクリプト群です（`utils/bin/`配下）。

| スクリプト | 概要 |
|-----------|------|
| [cc_dir_usage.sh](bin/cc_dir_usage.sh) | ディレクトリ単位のコスト（ccusage）を合計する |
| [cc_history2md.py](bin/cc_history2md.py) | 会話履歴（jsonl）をMarkdownに変換する |
| [cc_times.py](bin/cc_times.py) | セッションごとのAIの稼働時間を集計する |
| [commit_by_claude.sh](bin/commit_by_claude.sh) | ステージ済みの差分からコミットメッセージを生成してコミットする |

## 前提

| ツール | 使うスクリプト |
|--------|---------------|
| `jq` | `cc_dir_usage.sh` |
| `npx`（Node.js） | `cc_dir_usage.sh`（`ccusage`を実行するため） |
| `claude`コマンド | `commit_by_claude.sh` |
| Python 3 | `cc_history2md.py`, `cc_times.py`（標準ライブラリのみ） |

## 会話履歴の保存場所

ClaudeCodeは会話履歴を`~/.claude/projects/<ディレクトリ名>/<セッションID>.jsonl`に保存します。`<ディレクトリ名>`は作業ディレクトリの絶対パスの`/`や`.`などを`-`に置き換えたものです（例: `/Users/foo/my.app` → `-Users-foo-my-app`）。`cc_dir_usage.sh`・`cc_times.py`はこの規則でディレクトリを特定します。

## cc_dir_usage.sh

指定ディレクトリ（省略時はカレントディレクトリ）で行ったセッションだけのコストを合計して表示します。

```bash
cc_dir_usage.sh [dir]
```

`ccusage session --json`の出力にはプロジェクトのパスが含まれず、セッションID（`period`）でしか識別できません。そこで`~/.claude/projects/<ディレクトリ名>/`配下の`*.jsonl`のファイル名（＝セッションID）の一覧を作り、ccusageの出力とID一致で絞り込んで`totalCost`を合計します。

- 出力は合計コスト（数値のみ）です。
- 対応する履歴ディレクトリがない場合はエラー終了します。
- 初回は`npx`が`ccusage`を取得するため、時間がかかることがあります。

## cc_history2md.py

会話履歴ファイル（`<セッションID>.jsonl`）を読み、Markdownに整形してファイルに出力します。

```bash
cc_history2md.py [-o output-file] [-y] [-u] [-t] [-i] input-file
```

| オプション | 説明 |
|-----------|------|
| `-o`, `--output` | 出力ファイル（既定: `history.md`） |
| `-y`, `--yes` | 出力ファイルが既にあっても上書き確認をしない |
| `-u`, `--user-only` | ユーザーの入力のみ出力する |
| `-t`, `--no-tool` | ツール呼び出しとその実行結果を含めない |
| `-i`, `--no-info` | 先頭のセッション情報（ID・日付・モデル・作業ディレクトリ）を含めない |

- ユーザーの入力、アシスタントの応答、ツール呼び出し（Bash/Read/Write/Edit等）と実行結果を時系列で出力します。実行結果は折りたたみ（`<details>`）になります。
- IDEが自動で付与する通知（`<ide_...>`）やAPIエラーのメッセージは出力しません。
- 履歴はプロンプトや作業内容がそのまま含まれるため、共有する前に内容を確認してください。

```bash
# ユーザーの入力だけを抜き出す
cc_history2md.py -u -i -o tmp/prompts.md ~/.claude/projects/<ディレクトリ名>/<セッションID>.jsonl
```

## cc_times.py

セッションごとのAIの稼働時間を集計して表示します。

```bash
cc_times.py [-c dir | -d projects-dir]
```

| オプション | 説明 |
|-----------|------|
| `-c`, `--cwd` | 対象のディレクトリ（既定: カレントディレクトリ）。履歴の保存先はこのパスから決まる |
| `-d`, `--direct` | `~/.claude/projects/`配下の履歴ディレクトリを直接指定する（ディレクトリ名を変えた場合など） |

`-c`と`-d`は同時に指定できません。

表示項目は、セッションごとの開始時刻（Start）・最終レコードの時刻（Latest）・セッションID・ターン数・稼働時間・最初のプロンプトの冒頭と、全体の合計です。

Prompt列には、セッション内で最初の「ユーザー自身の入力」を表示します。スキルやスラッシュコマンドは`/名前 引数`の形で入力として扱いますが、`/clear`のように内容を持たないコマンドは飛ばします（飛ばすコマンドはスクリプト内の`SKIP_COMMANDS`で変更できます）。バックグラウンドタスクの完了通知とEscによる中断の記録も入力として扱いません。該当する入力がないセッションは空欄になります。

稼働時間は、履歴のタイムスタンプから次のように算出します。

- ユーザーが入力した時刻から、次の入力の直前の最終レコードの時刻までを1ターンとして合計します。
- ユーザーが次の入力を考えている待ち時間は含みません。権限確認の待ち時間は含まれます。
- サブエージェント（`isSidechain`）のレコードと、IDE通知のみの入力は除外します。
- `/clear`などのスラッシュコマンドも1ターン（0秒）として数えます。

## commit_by_claude.sh

ステージ済みの差分（`git diff --cached`）をClaudeに渡してコミットメッセージを生成し、確認のうえでコミットします。

```bash
commit_by_claude.sh [-j|--japanese]
```

| オプション | 説明 |
|-----------|------|
| `-j`, `--japanese` | コミットメッセージを日本語で生成する（既定は英語） |

1. ステージ済みの変更がなければ、メッセージを表示して終了します。
2. 差分を`claude -p`に渡し、コミットメッセージのみを生成させます。
3. 生成したメッセージを表示し、`y`を入力した場合のみ`git commit`を実行します。それ以外はキャンセルします。

- 差分の全文がClaudeに送られます。機密情報が差分に含まれていないか、ステージする前に確認してください。
- 差分は一時ファイル（`/tmp/git_diff.txt`）に書き出し、終了時に削除します。
- コミットだけを行い、`git push`はしません。
